## Protected System Rule

Existing cron jobs, skills, automations, configs, credentials, memories, wrappers, and workflows are protected production assets.

```text
Preserve what already works.
```

No protected system may be edited, disabled, renamed, deleted, merged, or moved without a specific approved work card.
